# E-Commerce Sales Analytics Dashboard

## Overview
This repository contains a comprehensive e-commerce sales dataset and analytics dashboard covering the period **January 2024 – December 2025**. The data includes 2,000 orders across multiple product categories, customer segments, locations, and payment methods in India.

## Dataset Summary

| Metric                  | Value              |
|-------------------------|--------------------|
| Total Orders            | 2,000              |
| Total Net Sales         | ₹11,13,66,542.96   |
| Total Profit            | ₹3,68,90,356.78    |
| Profit Margin           | 33.13%             |
| Delivered Orders        | 1,314 (65.7%)      |
| Returned Orders         | 350 (17.5%)        |
| Cancelled Orders        | 336 (16.8%)        |

## File Structure

| Sheet Name               | Description                                      |
|--------------------------|--------------------------------------------------|
| **Master_Data**          | Complete transactional data (Order-level details)|
| **Sales_by_Category**    | Net Sales by Category and Subcategory            |
| **Sales_by_Location**    | Net Sales by State and City                      |
| **Monthly_Sales**        | Monthly Net Sales for 2024 & 2025                |
| **Payment_Method_Sales** | Net Sales by Payment Method                      |
| **Profitability_by_Category** | Net Sales & Profit by Category              |
| **Order_Status_Summary** | Order Status Distribution                        |
| **Final Dashboard**      | High-level KPI summary                           |

## Key Columns in Master_Data

- **Order Information**: Order_ID, Order_Date, Order_Status, Return_Flag  
- **Customer Information**: Customer_ID, Customer_Name, Customer_Segment, City, State  
- **Product Information**: Product_ID, Product_Name, Category, Subcategory  
- **Sales Metrics**: Quantity, Unit_Price, Gross_Sales, Discount_Pct, Discount_Amount, Net_Sales  
- **Cost & Profit**: Cost, Shipping_Cost, Profit  
- **Other**: Payment_Method, Sales_Channel, Year, Month  

## Categories Covered
- **Beauty**: Haircare, Makeup, Personal Care, Skincare  
- **Electronics**: Accessories, Headphones, Laptops, Mobiles  
- **Fashion**: Bags, Footwear, Men Clothing, Women Clothing  
- **Home & Kitchen**: Furniture, Home Decor, Kitchen Appliances, Storage  
- **Sports**: Equipment, Fitness, Outdoor, Sportswear
